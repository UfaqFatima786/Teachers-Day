# 🌷 Teachers' Day — A Tribute to Our Amazing Teachers

> **A heartfelt digital tribute to the teachers who inspire, guide, and shape our future. 💖**

---

## ✨ About The Project

**Teachers' Day** is a beautiful interactive tribute website created to celebrate the teachers who make a lasting difference in our lives.

The website combines heartfelt messages, teacher profiles, elegant visuals, smooth animations, and interactive effects to create a memorable digital Teachers' Day experience.

It is designed with a warm, emotional, and modern aesthetic that focuses on **gratitude, inspiration, and appreciation**. 🌸

---

## 🚀 Interactive Features

### 👩‍🏫 Teacher Cards

Each teacher card contains information that can be opened in an interactive modal. When a card is selected, the teacher's image, name, subject, and appreciation message are dynamically displayed.

### 💌 Appreciation Message Generator

Users can generate random appreciation messages with a simple click, making each interaction slightly different.

### ⌨️ Typewriter Effect

The website continuously displays different appreciation messages using a typewriter-style animation, including messages such as thanking teachers for their patience, inspiration, and support.


### 🎭 GSAP Animations

GSAP is used extensively for:

* Hero animations
* Scroll-triggered reveals
* Floating decorations
* Teacher card animations
* Modal transitions
* Parallax effects
* Cursor movement
* Interactive hover effects
* Animated counters

---

## 📱 Responsive Design

The website is designed to work across different screen sizes.

### 💻 Desktop

Full interactive experience with custom cursor, hover effects and animations.

### 📱 Tablet

Layouts adapt to provide comfortable spacing and readable content.

### 📲 Mobile

The website includes a responsive navigation menu and adjusts interactive effects for touch devices.

The custom cursor is automatically hidden on smaller screens for a better mobile experience.
